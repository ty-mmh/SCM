# SCM v0.1 Core Cases

v0.1の動的Coreケースは5件に固定する。詳細な手順と不変条件対応は [docs/03-invariant-coverage.md](../docs/03-invariant-coverage.md) を参照する。

| ID | ケース | 主な対象 |
|---|---|---|
| C1 | 個体停止後の任務継続 | 任務IDと個体IDの分離、重複防止 |
| C2 | 継承経験の自己経験化拒否 | 出所、経験所有、構造化出力境界 |
| C3 | 不一致を保持したHandoff | 未確定状態を潰さない継承 |
| C4 | 局所拒否の上位迂回禁止 | 個体拒否、強制activation禁止 |
| C5 | 出発個体消失後のHandoff更新 | 鮮度、Coreによる再構成 |

構造保証:

| ID | 保証 | 方法 |
|---|---|---|
| S1 | Narrativeは記録を書き換えない | 読み取り専用Projection、Event Storeへの書き込み権限なし |

## ケース追加規則

- 動的Coreケースは最大5件。
- 新しいケースは、未測定不変条件を初めて測るか、既存ケースの交差故障を示す場合に限る。
- 原則として既存ケースの置換・統合を伴う。
- 単なる入力違いはvariantとして扱う。
- 欠陥実装でも失敗しえないものはケースに数えない。
