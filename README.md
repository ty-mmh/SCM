# Shared Continuity Model (SCM)

Shared Continuity Model（共有連続性モデル、SCM）は、複数の実行個体が、記録・記憶・共有状態・目的・権限・任務来歴からなる共有連続性基盤へ接続し、各個体の局所自律と実体固有性を保ちながら、個体の停止・交換・追加をまたいで一つの系として活動を継続するための構成的参照アーキテクチャです。

共有されるのは意識や瞬間的判断ではありません。共有されるのは、**系としての連続性**です。

## 中心となる問い

> 個体Aが消え、個体Bが活動を継続するとき、何を系として保持し、何をBへ継承し、何を継承してはならないか。

SCMは、既存システムを分類する診断器具だけを目的としません。第一の目的は、個体交代をまたいで任務・進捗・記録・記憶・未確定状態・権限を保持する構造を実装することです。ケースと診断は、その構造と並行して作り、観測結果を構造へ還流させます。

> **構造なき診断を先行させない。診断なき構造を固定しない。**

## SCMが扱わない主張

SCMは、意識・主観的自己・人格が個体間を移動したと主張しません。また、単なる共有データベース、中央遠隔制御、完全同期クローン、一般的なマルチエージェント構成をSCMと同一視しません。
