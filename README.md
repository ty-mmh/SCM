# Shared Continuity Model (SCM)

Shared Continuity Model（共有連続性モデル、SCM）は、複数の実行個体が同時または通時的に、記録・記憶・共有状態・目的・権限・任務来歴からなる共有連続性基盤へ接続し、各個体の局所自律と実体固有性を保ちながら、個体の停止・交換・追加をまたいで一つの系として活動を継続するための構成的参照アーキテクチャです。

共有されるのは意識や瞬間的判断ではありません。共有されるのは、**系としての連続性**です。

## 中心となる問い

> 個体Aが消え、個体Bが活動を継続するとき、何を系として保持し、何をBへ継承し、何を継承してはならないか。

SCMは、既存システムを分類する診断器具だけを目的としません。第一の目的は、個体交代をまたいで記録・記憶・想起・物語・任務来歴を保持する構造を実装することです。ケースと診断は、その構造と並行して作り、観測結果を構造へ還流させます。

> **構造なき診断を先行させない。診断なき構造を固定しない。**

## 三つの主要成果物

### 1. キュゥべえモデル研究ノート

SCMへ至った着想と構造抽出を保存する非規範の根源文書です。作品上の目的・倫理・感情・契約行為、ならびに商業・投資上の含意は構造核から切り離しています。

### 2. SCM概念設計

作品固有の含意を除いた一般正典です。生成AI、ソフトウェアエージェント、将来のPhysical AIを射程に含み、同時複数個体と通時的な個体交代の双方を扱える構造を保持します。

### 3. SCM v0.1生成AIモデル継承プロファイル

最初の実装断面です。同時に活動する個体数を一つへ限定し、生成AIモデルの切替を通じて、記録・記憶・想起・物語・任務来歴が系として継続する構造を作ります。

## SCMが扱わない主張

SCMは、意識・主観的自己・人格が個体間を移動したと主張しません。また、単なる共有データベース、中央遠隔制御、完全同期クローン、一般的なマルチエージェント構成をSCMと同一視しません。
