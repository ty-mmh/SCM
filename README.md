# Shared Continuity Model (SCM)

Shared Continuity Model（共有連続性モデル、SCM）は、複数の実行個体が同時または通時的に、記録、個体帰属付き記憶の共有書庫、共有状態、原則、権限、任務来歴、系の物語からなる共有連続性基盤へ接続し、各個体の局所自律と実体固有性を保ちながら、個体の停止・交換・追加をまたいで一つの系として活動を継続するための構成的参照アーキテクチャです。

共有されるのは意識、主観的自己、経験主体、瞬間的判断ではありません。共有されるのは、**系としての連続性**です。

## 中心となる問い

> 個体Aが消え、個体Bが活動を継続するとき、何を系として保持し、何をBへ提示し、何をB自身の経験として継承してはならないか。

SCM上の系は内在的な目的を持ちません。任務には外部の契機による局所目的がありえますが、系の継続は自己保存目的ではなく、ユーザーが終了を宣言するまでの運用状態です。

SCMプロジェクトの第一目的は、個体交代をまたいで記録、個体帰属付き記憶、想起、物語、任務来歴を保持する構造を実装することです。ケースと診断は、その構造と並行して作り、観測結果を構造へ還流させます。

> **構造なき診断を先行させない。診断なき構造を固定しない。**

## 現在の中心命題

> **記録は出来事を保持し、記憶は形成個体に帰属し、物語は系に帰属する。**

> **系は個体記憶を融合せず、帰属を維持した共有書庫として保存する。**

> **後継個体は、前個体の記録と記憶を自己経験として受け取るのではなく、他者の書物として読む。**

> **系の開始・切替・分岐・終了・破棄は、系の外部にいるユーザーが担う。**

## 三つの主要成果物

### 1. キュゥべえモデル研究ノート

SCMへ至った着想と構造抽出を保存する非規範の根源文書です。作品上の目的・倫理・感情・契約行為、ならびに商業・投資上の含意は構造核から切り離しています。

### 2. SCM概念設計

作品固有の含意を除いた一般正典です。生成AI、ソフトウェアエージェント、将来のPhysical AIを射程に含み、同時複数個体と通時的な個体交代の双方を扱える構造を保持します。

七概念の存在論と、個体帰属付き記憶の共有書庫を正典追補として分離しています。

### 3. SCM v0.1生成AIモデル継承プロファイル

最初の実装断面です。同時に活動する個体数を一つへ限定し、ユーザーによる生成AIモデルの切替を通じて、記録、個体帰属付き記憶、想起、物語、任務来歴が、経験帰属を融合せず継続する構造を作ります。

## 現在の状態

- 文書版: `v0.1-draft`
- 実装状態: 未実装
- SCM概念の射程: ソフトウェア実行個体、生成AI、将来のPhysical AI

v0.1はSCM全体の完全適合実装ではなく、**モデル切替をまたぐ共有連続性の限定された垂直スライス**を作る段階です。

## SCMが扱わない主張

SCMは、意識・主観的自己・人格が個体間を移動したと主張しません。また、自己保存目的を持つ系、経験帰属を区別しない共有データベース、中央遠隔制御、完全同期クローン、一般的なマルチエージェント構成をSCMと同一視しません。
