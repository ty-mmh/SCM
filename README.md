# Shared Continuity Model (SCM)

Shared Continuity Model（共有連続性モデル、SCM）は、複数の実行個体が同時または通時的に、記録、個体帰属付き記憶の共有書庫、共有状態、原則、権限、任務来歴、一つの正典Narrative系列からなる共有連続性基盤へ接続し、個体の停止・交換・追加をまたいで一つの系として活動を継続するための構成的参照アーキテクチャです。

共有されるのは意識、主観的自己、経験主体、瞬間的判断ではありません。共有されるのは、**系としての連続性**です。

## 中心となる問い

> 個体Aが消え、個体Bが活動を継続するとき、何を系として保持し、何をBへ継承し、何を継承してはならないか。

SCMの第一目的は、この問いへ動く構造で答えることです。ケースと診断は、その構造と並行して作り、観測結果を構造へ還流させます。

> **構造なき診断を先行させない。診断なき構造を固定しない。**

## 現在の中心決定

- **系は内在的な目的を持たない。** 自己保存、自己改善、関係継続を目的として内蔵しない。
- **記録は出来事に属する。** 内容の真偽ではなく、型を持つ出来事が外部化されたことを保持する。
- **記憶は形成個体に属する。** 系は個体記憶を一つの系記憶へ融合しない。
- **保存場所と可読性は共有されるが、経験主体は共有されない。** 後継個体は過去の記憶を他者の書物として読む。
- **系は一つの正典Narrative系列を持つ。** 各Revisionは生成・採用時に固定され、同じ資料からの再生成を同一Revisionとはみなさない。
- **ユーザーは系の外部共同構成者・ライフサイクル操作者である。** 作成、モデル切替、分岐、終了、論理破棄はユーザー起点とする。

## SCM v0.1生成AIモデル継承プロファイル

最初の実装断面では、同時に活動する個体数を一つへ限定します。

```text
N_active = 1

T1: Instance A / Model A
T2: Instance B / Model B
T3: Instance C / Model C
```

v0.1は、一人の信頼済みローカルユーザーが一つのローカルSCM系を操作するプロファイルです。ユーザー参照は固定値 `local-owner` として扱い、複数ユーザー、クラウド認証、管理者権限分離は将来へ延期します。

モデル切替時には、宛先未確定のHandoffをSCM Coreが生成します。後継個体は受領EventによってHandoffへ結び付けられ、Handoff本体は書き換えません。

個体の行為または非行為は、形成個体へ帰属する `MemoryEntry` を自動生成します。結果が未確定の間は `pending`、結果Eventが接続された後は `closed` とします。

正典Narrative Revisionは、系の作成時およびモデル切替を含む重要なライフサイクル節目で生成候補となり、`local-owner` の採用操作によって固定されます。v0.1ではNarrativeをRecallや行為判断には使いません。

## SCMが扱わない主張

SCMは、意識・主観的自己・人格が個体間を移動したと主張しません。また、単なる共有データベース、中央遠隔制御、完全同期クローン、一般的なマルチエージェント構成をSCMと同一視しません。
